# 臻享住展示网站

纯静态网站，发布目录 `dist`，无需安装依赖或运行构建命令。

## 内容

- 酒店抖音运营、品牌合作方案和招商咨询。
- 门店地区筛选、关键词搜索、营业状态、分页和详情。
- 官方抖音链接由品牌方提供；电话：18942914027。
- 支持减少动画设置；无后台、资料收集或在线预订功能。

## 数据口径

门店来自品牌方提供的《门店记录表.xlsx》，共1127条已认领且门店ID唯一的记录。按提供的记录，正常营业1010家、暂停营业48家、永久停业50家、状态未注明19家；覆盖25个省级地区和144座城市。名单并非实时数据，默认筛选正常营业。

公开数据仅保留名称、省份、城市、行政区、详细地址、门店类型和营业状态。没有上传原始表格、门店电话、内部ID、备注、资质字段及协议原件。

合作费用根据《开发方案》整理，最终以正式签约协议为准。抖音短链接保留品牌方提供的原值，外部页面受访问限制，未独立确认当前跳转落点。
